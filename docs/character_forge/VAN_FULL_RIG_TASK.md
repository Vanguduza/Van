# VAN Full Rig Task — M3 Execution View

Start only from an M2 owner-PASSed frozen skeleton. Implement all 18 durable states and all
14 finite actions from `visual-authority/rive_contract.json` without duplicating the
character per state or changing the public wire surface.

Every durable state needs entry, steady loop and exit. Every finite action needs
anticipation, main pose and return to the underlying state. Speech and gaze must continue
where the contract requires. URGENT/ERROR/WARNING must be readable by posture/motion rather
than colour alone.

Export a new full candidate, record its receipt and stage it. Full staging is deliberately
blocked unless the M2 core baseline screenshots have been admitted. The emulator then
checks the complete matrix and the independent reviewer records PASS/FAIL.
