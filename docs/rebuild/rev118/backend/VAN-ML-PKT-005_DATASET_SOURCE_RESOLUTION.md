# DatasetManifest candidates and actual native source resolution

Status: candidate source component. ML005 remains IN_PROGRESS. A parsed or source-inspected candidate is not an admitted DatasetManifest, licensed dataset, independent qualification or unit acceptance.

The existing VATI schema owner now registers an exact copy of the frozen DatasetManifest wire schema. The original package is unchanged. `DatasetManifestCandidate` bounds raw bytes and references, rejects duplicate JSON keys, nonfinite values, unknown versions/fields, ambiguous IDs, bad digests and boolean/overflowing counts. It preserves an immutable canonical representation and returns copies to callers.

Local temporal checks enforce availability <= cutoff <= creation. UTC offsets are explicit; unknown negative-zero offsets and unsupported clocks refuse. Subsecond comparison uses exact fractions rather than epoch floats or datetime microsecond rounding. RFC3339 ASCII digits are enforced. Corrected research is distinct from as-observed and cannot claim SHADOW/LIVE_ADVISORY use. These checks establish local consistency, not observed creation time, native clock qualification or source rights.

The real `vati research` CLI and slow workflow expose `dataset_manifest_check` and `dataset_source_inspect`. Nested duplicate keys are refused before reference resolution. Valid local checks return UNRESOLVED_DATASET_CANDIDATE and explicit outstanding references; no READY or permission result is produced.

`NativeDatasetSourceInspector` reads actual immutable Parquet/private source bytes through `NativeBarPartitionService.read`, which independently resolves the original native archive. It compares declared media type, byte length and SHA with the actual artifact; checks native scope, pinned source cutoff, actual row order/identity/count and exact availability. Duplicate/overlapping revised rows are not sorted away, averaged or silently dropped. The native source path cannot call reconstructed/provider availability or corrected-research ownership proven. A single source-window manifest resolves against its original durable object; a compound list hash is deliberately left unresolved without its actual durable source manifest.

Source and decoded-row budgets refuse before use and do not truncate. Returned source facts retain native scope, individual windows/revisions, coverage uncertainty, local-capture clock basis and false qualification flags. Actual source bytes do not prove canonical project/cohort/instrument binding or fixture origin. Scope, creation time/current policy, calendar/universe/feature/target references, owner consent and provider data-use entitlements remain unverified. No provider licence or consent format is created.

Actual failures and reports are retained under `ci/dataset_source_resolution_20261026` and `receipts/DATASET_SOURCE_RESOLUTION_20261026.json`. A duplicate-key CLI regression was reproduced before correction. The first inspect test envelope omitted expected_scope and is recorded as a harness error; the corrected envelope reproduced the parser-order failure. Remaining ML005 work includes complete immutable DatasetManifest publication, canonical scope and actual feature/target/universe/calendar owners, effective lifecycle and gap policy, real entitlement/consent/current policy, licensed news/expectation joins, reconstructed and corrected-research branches, and complete producer/consumer integration. Neither source presence nor a passed component suite closes these obligations. PRE/independent/native/owner/economic/production/S24 gates remain unissued.
