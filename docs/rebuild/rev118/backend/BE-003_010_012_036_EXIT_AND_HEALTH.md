# Candidate protective-exit durability and learning clocks

The existing router cleared pending-close state on UNKNOWN, allowing the next mark to send another close. Transport failures also had no durable request record. Seven regression failures reproduced missing restart protection, repeated unknown partial exits and malformed terminal receipts. Separately, three health tests showed diagnostic polls and duplicate evidence advancing the sustained-breach counter.

The real router now uses the existing account ledger transaction owner to commit EXIT_ATTEMPT before close transport. The original provider receipt, disposition and any owner SELL-ticket definition commit together. Unknowns, partial nonfinal results, missing or inconsistent fill evidence, and interruption before receipt commit retain the request fence and require reconciliation. A definitive zero-fill rejection permits a later new attempt. A full confirmed close cannot be sent again merely because a stale projection still contains the position. Legacy native UNKNOWN close receipts also remain fenced after upgrade. This does not guarantee an external venue's exactly-once behavior or provide missing broker-specific reconciliation.

The actual account owner-confirmation path settles only the original native ticket/request and an exact durable account-service receipt. A final partially executed owner ticket records the known residual and retains its protection; a distinct new ticket may then close that remainder. Wrong-ticket, unpersisted and model-produced assertions refuse settlement. Generic market marks and preservation actions share the same producer, journal and consumer path.

Actual account/single-symbol close handlers retain entries when exit price is missing or nonfinite, allowing later reconciliation without creating a fictitious result. Resting-entry fills retain their recorded fees. Strategy-health hysteresis now advances once per distinct admitted observation; verdict and adjustment reads are pure, so warm/cold polling frequency cannot change demotion timing.
