# BE-008: durable scoped native quote snapshots

Status: source-tested component; no unit or full-run acceptance.

NativeQuoteCollector captures a selected native quote on the independent read-only socket, closes and joins that reader, then retains its final resource diagnostic alongside the complete captured native product contract and quote. Native account, host/environment, product and contract revision stay bound. The immutable capture includes the original maximum-age policy, native side times, host processing/evaluation times and declared observation state. Exact decimal prices, age/chronology, subscription/control state, scope, hashes and capacity conservation are independently validated before persistence and during cold reads. ACK without data, malformed or exhausted diagnostics, stale/crossed prices and changed contracts cannot produce a durable empty or live success.

The existing bar archive's atomic record commit, original-request lookup, derived head repair, chain verification, revisions, as-of availability, scoped request locks and independent readback are shared through narrow validation/availability hooks. Existing bar formats and hashes are preserved. An actual baseline implementation from committed ad1d3941 generated a capture that the new implementation reads and replays with identical receipt and JSON bytes; the raw baseline files and script are retained. No existing record or frozen package byte is rewritten.

SPOT partitions preserve historical quote captures separately from bar intervals. Original replay checks both expected contract revision and the original maximum-age policy before any native connection. Lost record/head acknowledgements recover the original without recapture. A spawned process is killed by its fixture immediately after the actual atomic record write; cold recovery repairs the derived index and retains the original reference/time. Eight concurrent identical collectors use one actual framed native fixture connection and one receipt. Corrupt history refuses reads instead of substituting a fresh capture.

Receipt state is HISTORICAL_QUOTE_CAPTURE_UNQUALIFIED; current freshness is explicitly NOT_EVALUATED_HISTORICAL_RECORD. Host processing is not network receipt, metadata at processing is not proven effective at the original tick, and resource accounting is not a source or continuity certificate. These are snapshots, not a complete tick/live-bar stream. All raw provider/authority flags remain false/NONE. Qualified producers/consumers, source health/entitlements/calendars/depth, service/host isolation and production capacity remain open. The archive cannot authenticate an adversarial full rewrite or detect external deletion of every record and anchor.
