# Durable original partial-depth capture

BE-008 remains IN_PROGRESS; unit/native/provider acceptance is NOT_ISSUED.

The new NativeDepthArchive extends the existing NativeMarketArchive owner. Its DEPTH partition reuses the original atomic record commit, scoped request locks, immutable revision chain, independent durable readback and recoverable derived index. Existing SPOT/bar partitions remain distinct. Original requests retain their captured contract revision, processing-age policy and display limit. A replay reads or reconciles that original capture and never fetches a replacement from the broker.

Capture validation retains exact unsigned quote IDs/prices/cent sizes and checks scope, native contract revision, canonical integer text, unique quote identities, side/order/count/display consistency, causal host clocks, original read capacity and all unqualified states. Resealing a modified body cannot turn false flags into numeric zero, supply a native timestamp/sequence, normalize an undocumented price scale, assert complete/executable depth, or admit an exhausted source worker. Host processing time remains distinct from native time and network receipt.

NativeDepthCollector calls the existing independent market reader and closes/joins it before taking the final capacity diagnostic and publishing. Failed, foreign, changed, untyped or unavailable source results do not publish an empty success. A real committed record with a lost head update recovers through the existing owner; corrupted records or conflicting/ahead indexes refuse without recapturing. Revision/as-of reads retain historical availability and explicitly do not evaluate current freshness. Empty observed partial depth never proves an empty market.

Actual source evidence: 48 new cases; 175 focused depth/quote/archive/collector passes; final combined 786 passes on SQLite and an actual isolated PostgreSQL instance, zero skips or storage-audit violations. All 494 runtime/test source hashes matched; the owned fixture was independently absent after cleanup. The cases include a real child-process crash before head publication, cold-owner recovery, parallel collectors producing one native read/revision, actual framed depth capture on a separate socket, original-policy replay and source-result closure. Six supplemental faults were caught, with 48 positive and 48 restored controls and exact source restoration. Counts overlap; supplemental faults are separate from the canonical corpus.

Archive validation proves captured format/consistency, not broker origin, feed rights, native continuity or a qualified liquidity model. Source fixtures do not establish those facts. The depth price scale, native timestamp/sequence, snapshot completeness, provider entitlement/health, service and existing-screen consumption, tick fanout, other venues and the remaining BE-008 operations still require implementation and qualification. This module enables no HTTP fact injection, frontend feature, native provider activation, order or payment. Full backend/ML/assistant, production-profile provisioning, signing/deployment and actual Android/Artemis/S24 acceptance remain required; no frontend redesign precedes BG-001.
