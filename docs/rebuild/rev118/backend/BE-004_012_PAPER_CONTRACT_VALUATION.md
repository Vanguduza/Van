# Candidate contract-specific paper valuation

The actual single-symbol and account coordinator factories now bind paper simulation to every configured `SymbolContract`. Simulated price P&L uses that symbol's account-currency tick value divided by tick size. Long/short marks, partial exits, final exits and resting-order fills keep the same factor. A gold or index contract no longer inherits the unrelated 100,000-unit FX lot default.

The paper account's registered currency must match the contract's account currency. No conversion rate is guessed. Non-finite, zero or negative tick values/sizes are refused before runtime storage is opened. A configured simulation rejects an unknown symbol or different loss model before opening or resting an order. Its working factors are copied from the input map; later map edits cannot silently rescale money. Rebinding cannot change the units of an open position or pending order.

The backtest factory binds the same contract and account currency. The legacy standalone `PaperAdapter` scalar seam remains for isolated fixtures; actual configured single-symbol, multi-instrument and backtest producers supply contracts. Existing native-provider transports are unchanged. Full-stake contracts retain their existing simulation semantics; this packet does not invent a fixed-payout/options payoff model.

The source tests drive actual service constructors and native simulation methods. They check long and short P&L, partial cash plus remaining unrealised money, unknown instruments, currency conflicts, invalid numerical units, pending-order rebinding, actual backtest currency and the real PostgreSQL-backed multi-instrument constructor with two distinct tick valuations. Initial valid counterexamples produced four assertion failures. An earlier short-side fixture had an incorrect protective-stop side and was corrected before those valid counterexamples were recorded.

See `receipts/PAPER_CONTRACT_VALUATION_SOURCE_20261022.json` for exact source, control, full-suite and injected-fault evidence. This is candidate BE-004/009/012 source work, not a claim that simulated profits establish profitability or provider execution. Actual spread/slippage calibration, commission/carry/contract-payoff completeness, native contract currency verification, persistent paper state, single-symbol restart recovery and original provider/independent/production/handset gates remain separate obligations.
