# Exact trade approval and emergency-close truth

Ten counterexamples demonstrated that an actual approved RiskDecision could authorize a changed stop, account, idempotency key, strategy version or direction while retaining the original intent ID. Both router modes, including production pre-trade controls, submitted these altered intents. Comparing a quantized order against the already altered intent did not bind it to the original Risk Authority evaluation.

New approvals carry `approval_schema_version: 2`, a canonical hash of every serialized TradeIntent field and a canonical hash of the full current mandate. The outer decision seal includes both bindings. The router checks them before creating an order command, and pre-trade controls independently check the intent binding. Changing policy values under the same mandate ID/version requires re-evaluation. Existing first-refusal semantics for a different mandate identity or non-trading mode are retained. Hashes are integrity bindings within the existing trusted producer path; they do not create a new signing authority or replace owner admission.

Historical v1 decisions retain their exact representation and hash. They remain readable for historical accounting, but cannot authorize a new broker submission. V2 money-risk reconstruction also verifies that the original recorded intent matches the bound decision. Historical decision replay remains strict: running today's v2 evaluator against a v1 record reports divergence; exact byte replay requires the original evaluator/representation. No record is rewritten or silently upgraded.

The remaining emergency `STOP_REJECTED_FLATTEN` path now uses the durable protective-exit journal. An unknown, partial, incomplete or lost close response never reports a flattened position. Stop rejection is recorded before transport; unresolved recovery blocks new risk and survives router reconstruction. A genuine complete confirmed close retains the existing success reporting. Native broker reconciliation is still required to resolve uncertain external effects.
