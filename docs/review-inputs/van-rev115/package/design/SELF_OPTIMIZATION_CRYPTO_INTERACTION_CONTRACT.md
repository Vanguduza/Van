Both themes use the existing tokens/recipes. Learning-state chips are semantic text with restrained accents; profit color does not mark authority. Show inactive, warming, qualified-adaptive, fallback, researching, awaiting-authorization, revoked and degraded separately. Each visible status is supplied by the BE-032 consumer catalogue with real producer bindings.

An entry action must not imply a new owner confirmation for every permitted automatic operational choice. Manual order intent uses the existing configured owner/manual authority. New policy promotion shows the exact artifact, scope, uncertainty, permitted use and rollback, then invokes the existing signed promotion process.
