## Readiness and validation

All 180 application acceptance tests are **NOT_RUN**. All child implementation packets are **NOT_STARTED**. No model was trained, permission bought, real capture started, order sent, deployment changed or F15/BG-001 issued.

For document validation in a Python environment with `jsonschema` installed:

```sh
python verification/validate_blueprint.py
python verification/validate_blueprint.py --readiness
```

The first checks only the document properties and synthetic reference cases reported in `verification/DOCUMENT_CHECK_REPORT.json`. The second deliberately exits2 because document integrity is not application readiness. Neither command runs VAN, invokes a provider or validates actual independent authority.
