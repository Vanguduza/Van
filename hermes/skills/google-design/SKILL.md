# Google Design

## Canonical loop

```text
Project Truth + Visual Authority
  → Notebook design research
  → Mixboard divergence
  → VAN design critic
  → Stitch convergence
  → DDE/Figma normalization where applicable
  → implementation
  → visual acceptance
```

## Design Intelligence Packet

Before Mixboard/Stitch work, include project/screen IDs, Project Truth SHA,
Visual Authority reference, benchmark artifact hashes, locked functionality,
allowed exploration dimensions, forbidden changes, responsive/accessibility
constraints and acceptance criteria.

## Authority

Mixboard and Stitch generate artifacts; they do not define product requirements.
Generated screens must not invent functionality, security rules or business state.

## Routing

- `visual_ideation` → Mixboard first when available; Nano Banana is a bounded fallback.
- `ui_design` → Stitch first when available.
- `image_generation` → Nano Banana through Hermes media routing.

Record accepted and rejected candidates with provenance so the design path is reconstructable.
